# Python Programming Fundamentals - 10 Essential Exercises

This repository contains solutions to 10 fundamental Python programming questions covering strings, lists, dictionaries, iterators, and list comprehensions.

## Questions Overview

1.  **String Manipulation**: Reverse a string and extract every 2nd character.
2.  **List Comprehension**: Generate squares of even numbers from a list.
3.  **Frequency Count**: Count character frequency in a string using a dictionary.
4.  **Indexing**: Find indices of all odd numbers using `enumerate()`.
5.  **List Rotation**: Rotate a list to the right by `k` positions using slicing.
6.  **Dictionary Mapping**: Combine two lists into a dictionary using `zip()`.
7.  **Manual Iteration**: Use `iter()` and `next()` with `StopIteration` exception handling.
8.  **Flattening Lists**: Flatten a nested list using list comprehension.
9.  **Palindrome Check**: Verify if a string is a palindrome using slicing.
10. **Find Second Largest**: Locate the second largest number in a list without using `sort()`.
